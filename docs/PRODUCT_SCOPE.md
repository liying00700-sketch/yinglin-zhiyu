## 2. 独立产品的信息架构

独立产品保留品牌首页和六个任务入口：

1. **产品首页**：呈现“儿童学习×家庭育儿知识”的商业定位和知—行—观—长闭环；
2. **育儿问答**：问题描述、必要事实、安全分流、结构化回答、尝试反馈和有效方法；
3. **学习成长**：家庭成长环、周期摘要、七领域筛选、最近成长足迹；
4. **本周计划**：领域选择、年龄适配、7天计划、完成记录、计划换版；
5. **今日陪伴**：面向奶奶、爸爸、妈妈等任意照护者的简化执行视图；
6. **成长回看**：七领域记录分布、家人原话、偏难／抗拒信号和下一周提示；
7. **孩子档案**：最小必要资料、动态月龄、照护者称呼、数据边界说明。

核心闭环：

```text
设置孩子档案
→ 提问并补充必要事实
→ 安全分流与已准入资料检索
→ 获得一个最小行动并反馈效果
→ 生成本周计划
→ 家人完成一项活动
→ 留下投入／难度／原话
→ 成长总览形成学习证据
→ 成长回看提出下一周调整方向
```

## 3. 明确不带入独立产品的内容

- 萤林今日指挥台、导师团、记录中心、创作工坊、情报中心、投资和AI产品坊；
- 110张育儿知识卡浏览、收藏、142份资料目录和管理后台；
- 内容生产、小红书选题或对外发布能力；
- 医疗诊断、标准化发育测评、虚构同龄均值或能力排名；
- 支付、订阅、社区和复杂SaaS后台。

这些能力与“家庭成长执行闭环”不是同一个用户任务，独立产品第一版不应因复用方便而混入。

## 5. 数据与安全边界

- 不复制原萤林中的真实孩子昵称、出生日期或家庭观察；
- V0.1数据仅保存于当前浏览器的 `localStorage`；
- 问答正文、回答、反馈和有效方法同样保存在当前浏览器，最多保留50次问答；
- 红旗信号在调用模型前拦截；普通问答服务不可用时不生成演示答案；
- 浏览器只展示上游返回的来源名称和类型，不开放原文件、路径或下载；
- 当前资料目录虽有142份，但尚不能据此声称“完整知识库已接入”；实际可检索范围以版权、内容复核和后台准入状态为准；
- 这满足单设备产品验证和刷新持久化，但不等于生产级会员隔离；
- 对外部署前至少需要账号体系、家庭ID、服务端持久化、访问控制、删除／导出和审计日志；
- 所有量化只描述家庭自身记录，不用于诊断、能力排名或发育达标判断。
